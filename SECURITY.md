## Reporting a Vulnerability

The `rescat` project is a defensive cyber incident response and cryptanalysis toolkit designed strictly for lawful data recovery, digital forensics (DFIR), and malware analysis.

If you discover a security vulnerability, buffer handling issue, or cryptographic weakness within `rescat`, please report it privately:

- **Contact**: `sogutlueren@gmail.com`
- **PGP Key**: Available upon request.

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Potential impact on the host system.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.

## Ethical Use and Disclaimer

`rescat` is created for authorized incident responders, forensic investigators, and system administrators recovering their own data. Do not use this tool on systems or data without explicit written permission.
