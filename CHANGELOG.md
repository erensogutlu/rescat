## [1.0.0] - 2026-09-08

### Added
- **Autonomous Recovery Engine**: Zero-parameter automated case directory traversal, algorithm profiling, and multi-vector decryption.
- **Curve25519 (X25519) ECDH Hybrid Decryptor**: Key exchange reconstruction for LockBit 3.0, Akira, and Babuk.
- **Sosemanuk Stream Cipher**: High-speed ESXiArgs and Babuk virtual machine storage decryptor (eSTREAM Profile 1).
- **Intermittent / Stride Encryption Engine**: Block-skipping forensic detection and plaintext segment carving.
- **VMware ESXi .vmdk Reconstruction**: Partition scanner and `# Disk DescriptorFile` auto-generation for `-flat.vmdk`.
- **Active Process Freezing & RAM Snatcher**: Live `SIGSTOP` suspension and memory dumping for in-flight ransomware processes.
- **In-Memory Key Hunter**: Automated scanner for AES-128/256, ChaCha20, Salsa20, TEA/XTEA, RC4, and RSA keys in RAM dumps.
- **Nonce-Reuse Automatic Crib-Dragging**: Keyless plaintext recovery across multiple files encrypted with identical nonce.
- **Multi-Weak PRNG Cracker**: Knuth Subtractive Generator (.NET `System.Random`) and MSVC LCG seed bruteforcer.
- **OpenSSL Salted Automated Cracker**: SHA-256 EVP, MD5 EVP, and PBKDF2 dictionary and interactive recovery.
- **35+ Extended Format Validators**: FLAC, WebP, MKV, BZIP2, XZ, Zstandard, PCAP, DEX, RTF, and Chi-Square ($\chi^2$) structural variance test.
- **Multiprocessing Parallel Cracking Engine**: Multi-core CPU bruteforce with rule-based leet mutations and wordlist streaming.
- **DFIR Forensic Remnant Engine**: Windows VSS, Linux Btrfs/ZFS snapshots, SQLite WAL/journal recovery, and temporary office autosave carver.
- **Interactive Terminal Wizard (TUI)**: Two-choice automated terminal interface with real-time progress indicators.
- **Multi-Format Reporting**: JSON, Markdown, OASIS STIX 2.1 JSON, and self-contained interactive HTML reports.
